# モニタリング様式の調査メモ

「個別支援計画モニタリング」下書き生成機能(CHANGE-015、`app/api/monitoring/route.ts`)の設計根拠となった、様式調査の要点。

## 要点

- モニタリング記録の様式は国・東京都のいずれも定めていない → 様式非依存の構造化テキストとして出力するのが正しい設計方針。
- ただし「記録すべき内容」(面接の要点・モニタリング結果・計画変更の要否とその判断経過)は基準省令・自治体の指導資料に明示されている。
- 面接の実施・計画変更の判断は基準省令上AIで代替できない(職員が行う)。だからこの2項目はAI生成せず、空欄の入力欄として残している。
- 相談支援事業所が自治体に提出する別制度の「モニタリング結果報告書」と名称が衝突するため、本機能の画面上の名称は「個別支援計画モニタリング(下書き)」としている。

## 補足

出典URL・確度評価を含む詳細な調査資料は、本リポジトリ(`poc-app/`、実装)とは別に管理している業界リサーチ側にある。実装と調査で管理単位を分けているため、こちらには設計に必要な結論だけを転記している(内容のコピーによる二重管理のズレを避けるため)。
